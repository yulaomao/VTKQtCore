# 验证基线与回归样例

## 目标

本章定义判断第三方实现是否与当前项目一致的最小闭环，包括协议级、模块级、场景级、页面级和音频级验证路径。

## 一致性定义

第三方实现被视为“与当前项目一致”，至少要满足：

1. 公开协议字段名、枚举值、固定事件名和 moduleId 一致。
2. 模块切换、UI 动作、状态样本、SceneGraph 刷新和全局 UI 行为一致。
3. 关键模块的输入输出、页面刷新和场景变化一致。
4. 错误和连接状态能够沿统一链路被观察到。

## 现有验证入口

### 自动化/半自动化入口

- socket client 相关测试
- intermoduletest 跨模块测试模块
- datagen 模块的场景生成和音频测试入口

### 人工验证入口

- 模块页面交互
- VTK 3D 场景显示
- 壳层导航与状态栏
- 跨平台渲染外观

## 协议级验证样例

### 检查项

- Socket envelope 是否为 module/type/value 三字段结构
- AppMessage 字段名是否一致
- UiAction 的 actionType 是否为 custom_action
- LogicNotification 的 eventType、level、targetScope 是否可正确表达
- ModuleInvokeRequest/Result 是否可完整往返

### 最小样例

1. 发送一个 params/state 样本。
2. 发送一个 planning/action_request 动作。
3. 发送一个 shell/switch_module 动作。
4. 检查目标模块或壳层是否按预期响应。

## 模块级验证样例

### datagen

1. 创建一个 PointNode。
2. 修改颜色或显示属性。
3. 删除该节点。
4. 核对页面、摘要、3D 场景一致变化。

### params

1. 输入一组参数并应用。
2. 检查参数合法性和参数数量是否更新。

### pointpick

1. 注入点列表。
2. 检查点计数、点列表和 confirmed 状态。

### planning

1. 生成规划路径。
2. 检查状态文本、主窗口和概览窗口是否同步变化。

### navigation

1. 启动导航。
2. 注入远程位姿样本。
3. 检查状态、位置和 3D 场景更新。

## 场景级验证样例

### SceneGraph 节点一致性

- PointNode：点位置、颜色、大小、标签
- LineNode：顶点序列、线宽、闭合/虚线
- ModelNode：mesh、材质和边缘属性
- PlaneNode：平面填充和边框
- TransformNode：父子层级和世界变换

### 显示级一致性

- 节点新增后是否进入正确 renderer layer
- 节点删除后是否清理显示对象
- 批量修改是否避免多次无效重绘

## 页面级验证样例

### 模块切换

1. 通过导航条切换模块。
2. 确认中心页面切换。
3. 确认旧辅助区被清理。
4. 确认新辅助区被挂载。

### 通知刷新

1. 触发一个模块逻辑通知。
2. 确认页面控件和摘要区同步更新。
3. 确认无跨模块误刷新。

## 音频触发验证样例

### 单次播放

1. 触发 polling_progress。
2. 触发 polling_attention。
3. 确认两类提示音都可播放。

### 高频播放

1. 在 datagen 中连续高频触发同一提示音。
2. 确认不叠音。
3. 切换为另一提示音，确认旧播放被替换。

## 人工核对清单

- UI 布局是否与当前项目一致
- VTK 交互和渲染观感是否一致
- 全局通知、遮罩和错误提示是否符合预期
- Socket 断开、恢复后的状态表现是否合理
- 多平台下渲染外观是否明显偏离

## 已知限制

- 视觉风格、美观程度和交互动效无法完全自动验证
- 摄像机交互手感、渲染性能和跨平台图形差异主要依赖人工验证
- 某些业务流程需依赖真实外部服务或真实消息源

## 验收清单模板

```markdown
## 第三方实现一致性验收

### 协议层
- [ ] Socket envelope 使用 module/type/value
- [ ] AppMessage 字段名与枚举值一致
- [ ] UiAction.actionType 固定为 custom_action

### 运行时
- [ ] requestModuleSwitch 能触发标准模块切换链路
- [ ] global/shell/global-ui 三个目标域语义一致
- [ ] LogicNotification 能被正确路由到页面或壳层

### 模块与场景
- [ ] 五个主业务模块具备与当前项目一致的输入输出
- [ ] SceneGraph 节点类型和显示行为一致

### UI 与音频
- [ ] 页面切换与辅助区挂载一致
- [ ] polling_progress 与 polling_attention 行为一致
```

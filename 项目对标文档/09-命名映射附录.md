# 命名映射附录

## 目标

本附录列出当前仓库中的标准公开命名，并给出跨语言实现时的推荐映射方式。原则是：公开对象严格同名，内部实现只要求语义可追溯。

## 公开对象必须同名

### 目标域与模块注册名

| 类别 | 固定名称 |
| --- | --- |
| 特殊目标域 | global, shell, global-ui |
| 主业务模块 | datagen, params, pointpick, planning, navigation |
| 测试模块 | intermoduletest_a, intermoduletest_b |

### 消息类型与固定字符串

| 对象 | 固定名称 |
| --- | --- |

| UiAction::ActionType | custom_action |

## 推荐跨语言映射规则

### 可以按语言习惯调整的部分

| C++ 风格 | Python 示例 | C# 示例 | 要求 |
| --- | --- | --- | --- |
| getCurrentModule | get_current_module | GetCurrentModule | 语义必须不变 |
| setServerEndpoint | set_server_endpoint | SetServerEndpoint | 参数顺序和含义不变 |
| requestResync | request_resync | RequestResync | 语义不变 |

### 不建议改动的部分

- moduleId 字符串
- 事件名字符串
- JSON 字段名
- 枚举映射到外部字符串时的值

## 内部实现允许映射的部分

以下内容不要求逐语言逐成员同名，但必须在实现文档或代码注释中能映射回当前概念：

- m_nodes、m_registry、m_currentModuleId 等私有成员
- QMap、QVector、QHash 等容器的具体替代实现
- QObject 父子生命周期与目标语言的 GC/RAII/引用计数差异
- QReadWriteLock、QMetaObject::invokeMethod 等框架机制的等价替代

## 建议映射模板

```markdown
| 语义 | 当前 C++ 名称 | 目标语言名称 | 备注 |
| --- | --- | --- | --- |
| 当前模块 ID | m_currentModuleId | current_module_id | 私有成员可映射 |
| 页面栈切换 | switchToPage | switch_to_page | 公开行为需保留 |
| 模块切换请求 | requestModuleSwitch | request_module_switch | 公开行为需保留 |
```

## 使用规则

1. 对外可见字符串永远以本附录和通信章节为准。
2. 公开类名和函数名尽量保留原名，仅在目标语言命名规范强约束时做机械映射。
3. 私有成员和内部结构只要语义可追溯即可。

# 资源、主题与音频规范

## 目标

本章定义 qrc 资源、样式表、图标、音频预设和 PromptAudioService 的组织方式、命名规则、加载顺序与触发点。

## 资源目录与 qrc 组织

当前资源组织至少包含：

- [../src/resources/styles.qrc](../src/resources/styles.qrc)
- [../src/resources/audio/audio_prompts.qrc](../src/resources/audio/audio_prompts.qrc)
- [../src/shell/mainwindow.qrc](../src/shell/mainwindow.qrc)

### 资源路径约束

- 所有内置资源必须通过 qrc 路径引用
- 路径前缀固定使用 :/
- 文档、代码和跨语言实现中都不应把内置音频或样式写成操作系统文件绝对路径

## 样式系统

样式管理由 AppStyleManager 完成。

### 当前固定样式注册

| styleId | qrc 路径 |
| --- | --- |
| clinical-light | :/styles/styles/app-theme.qss |

### 应用顺序

1. 创建 AppStyleManager。
2. registerStyle(clinical-light, :/styles/styles/app-theme.qss)。
3. 如果 profile 或命令行指定 styleTheme，则优先 applyStyle(styleTheme)。
4. 如果 currentStyleId 仍为空，则 applyStyle(clinical-light)。

## MainWindow 资源

MainWindow 会加载窗口图标等壳层资源。当前主窗口图标来自 mainwindow.qrc 对应的资源项。

## 音频预设名

PromptAudioPresetIds 当前固定提供两个预设：

- polling_progress
- polling_attention

这些 ID 是公开协议级常量，不得随意更名。

## 音频预设注册时机

PromptAudioService 在 BaseSoftwareInitializer::initialize() 中创建，并在模块逻辑注册前注入 LogicRuntime。随后立即注册：

- polling_progress -> :/audio/prompts/news.wav
- polling_attention -> :/audio/prompts/news_anchor_female.wav

## PromptAudioService 真实行为

PromptAudioService 的目标不是“每次请求都无脑叠加播放”，而是提供稳定可控的提示音队列。

### 核心特征

- 维护 presetId 到资源路径的映射
- 对待处理请求做异步排队
- 支持相同请求去重
- 不同请求切换时中断旧播放并启动新播放
- 支持 stopPromptAudio()

### 音频后端选择

- 真正 WAV 文件优先使用 QSoundEffect
- 其他音频或非标准 WAV 回退到 QMediaPlayer

## 提示音触发点

当前系统中，提示音至少在以下场景中出现：

- BaseSoftwareInitializer 初始化阶段注册预设
- 模块逻辑通过 LogicRuntime 的音频接口触发预设播放
- datagen 页面存在用于测试单次和高频音频触发的入口

## 命名规范

### 预设 ID 命名

- 使用小写字母和下划线
- 反映业务语义，而不是底层资源文件名

### 资源 alias 命名

- 优先使用稳定别名，不直接暴露工作区根目录原始文件名
- 允许通过 qrc alias 把源文件名与对外资源名解耦

## 资源缺失与降级

### 样式

- 指定 styleId 不存在时，applyStyle() 返回 false
- 启动时应回退到默认主题 clinical-light

### 音频

- presetId 未注册时，不应导致程序崩溃
- 音频文件格式不满足 QSoundEffect 条件时，回退到 QMediaPlayer
- stopPromptAudio() 后后续播放仍应可恢复

## 冻结项

- styles.qrc、audio_prompts.qrc、mainwindow.qrc 这些资源组织入口
- clinical-light
- polling_progress、polling_attention
- :/styles/styles/app-theme.qss
- :/audio/prompts/news.wav
- :/audio/prompts/news_anchor_female.wav

# 通信协议与消息契约规范

## 目标

本章冻结系统公开协议、消息结构、字段语义、枚举值、固定字符串和 JSON 示例。跨语言实现必须以本章为准，不得擅自修改公开字段名和固定字符串。

## 外部 Socket envelope

当前系统对外兼容的 socket JSON envelope 结构为：

```json
{
	"module": "planning",
	"type": "state",
	"value": {
		"planPath": []
	}
}
```

### 字段定义

| 字段 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| module | string | 是 | 目标模块注册名，或 global |
| type | string | 是 | 消息类型 |
| value | object | 是 | 业务负载 |

### module 规则

- module 通常应与模块注册名一致。
- global 表示广播到所有模块，比较时大小写不敏感。

### 兼容 type 列表

| type | 含义 | 当前处理落点 |
| --- | --- | --- |
| action | 兼容 UI/控制动作 | LogicRuntime::onControlMessageReceived() |
| action_request | 控制动作请求 | LogicRuntime::onControlMessageReceived() |
| ui_action | 兼容 UI 动作 | LogicRuntime::onControlMessageReceived() |
| command | 兼容服务端命令 | LogicRuntime::onServerCommandReceived() |
| server_command | 服务端命令 | LogicRuntime::onServerCommandReceived() |
| resync_request | 请求重同步 | 统一重同步路径 |
| resync_response | 重同步响应 | 统一重同步路径 |
| heartbeat | 心跳 | 通信健康状态更新 |
| 其他类型 | 外部状态样本 | StateSample / AppMessageKind::ExternalData |

## ModuleUiEvent

ModuleUiEvent 是命名空间协议，不是独立 struct。其固定字符串如下：

| 名称 | 固定值 |
| --- | --- |
| command() | dispatch_module_ui_event |
| category() | module_ui_event |
| commandKey() | command |
| categoryKey() | eventCategory |
| eventNameKey() | eventName |
| sourceModuleKey() | sourceModule |

### createActionPayload() 行为

- 在 payload 中插入 command=dispatch_module_ui_event
- 在 payload 中插入 eventName

### createNotificationPayload() 行为

- 移除 command、targetModule、eventCategory、sourceModule、eventName
- 写入 eventCategory=module_ui_event
- 写入 eventName
- sourceModule 非空时写入 sourceModule

### isNotification() 判定条件

一个 LogicNotification 会被视为某模块可处理的 ModuleUiEvent，必须同时满足：

1. eventType == CustomEvent
2. targetScope == AllModules，或 targetScope == ModuleList 且目标模块包含当前模块
3. payload[eventCategory] == module_ui_event
4. payload[eventName] 非空
5. 如果调用时提供了 expected eventName，则必须完全相等

## 标准 JSON 示例

### 示例一：外部状态样本

```json
{
	"module": "params",
	"type": "state",
	"value": {
		"parametersValid": true,
		"parameterCount": 12
	}
}
```

### 示例二：UI 动作经 socket 外发

```json
{
	"module": "planning",
	"type": "action_request",
	"value": {
		"category": "ActionRequest",
		"actionType": "custom_action",
		"module": "planning",
		"payload": {
			"command": "next_step"
		},
		"origin": "client"
	}
}
```

### 示例三：模块切换动作

```json
{
	"module": "shell",
	"type": "action_request",
	"value": {
		"actionType": "custom_action",
		"module": "shell",
		"payload": {
			"command": "switch_module",
			"targetModule": "navigation"
		}
	}
}
```

### 示例四：模块 UI 事件载荷

```json
{
	"command": "dispatch_module_ui_event",
	"eventName": "refresh_target_panel",
	"targetModule": "params",
	"sourceModule": "planning"
}
```

- module、type、value
- messageId、correlationId、source、target、kind、eventName、timestampMs、payload、error
- actionId、actionType、module、timestampMs、payload
- notificationId、sourceActionId、eventType、level、timestampMs、targetScope、targetModules、payload
- requestId、sourceModule、targetModule、method
- command、eventCategory、eventName、sourceModule
- global、shell、global-ui
- external_data、ui_intent、module_event、outbound_command、shell_event、global_ui_event、error
- custom_action
- dispatch_module_ui_event、module_ui_event
- polling_progress、polling_attention

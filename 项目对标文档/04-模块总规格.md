## 统一规格模板

每个模块规格页至少回答以下问题：

1. 模块 ID、Page 类、Handler 类分别是什么。
2. 该模块负责什么，不负责什么。
3. 该模块接收哪些 UiAction、StateSample、ModuleInvoke。
4. 该模块发出哪些 LogicNotification 和自定义事件。
5. 该模块会如何影响 SceneGraph。
6. 该模块页面有哪些关键控件、VTK 窗口、辅助面板。
7. 典型工作流是什么。
8. 最小验证路径是什么。

## 通用约束

### 页面侧约束

- Page 只负责采集用户输入、显示状态和承载 VTK 窗口。
- Page 不直接操作 SceneGraph。
- Page 不直接访问其他模块 UI。

### 逻辑侧约束

- 模块行为以 ModuleLogicHandler 为真相入口。
- 跨模块协作优先使用 ModuleInvoke 或模块 UI 事件。
- 模块逻辑对 SceneGraph 的修改必须通过节点 API 完成。

### 通知侧约束

- 向 UI 的更新统一通过 LogicNotification。
- 模块内页面更新依赖 ModuleCoordinator::notificationForPage。
- 跨模块页面通信不允许直接传 QWidget 指针。
